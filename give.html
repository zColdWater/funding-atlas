Giving season 2026: where crypto donations to Ethereum public goods land

Last updated 2026-11-21 · 中文：年底捐赠季，捐给以太坊公共物品的官方渠道逐条核实；本页刻意不贴任何捐赠地址，请只从各项目官方页面复制。

GivingTuesday is 1 December 2026. If you plan to give crypto to Ethereum public goods this season, here is where you can give today and what to check first, verified against each project's own pages on the date shown. We list no donation addresses on purpose: copy them only from the official page linked on each card.

Before you send

  • Get the address from the project's own domain or docs — never from a reply, a DM, an ad or a search-result snippet. Fake "donation" accounts appear around every giving campaign.
  • Match the network. The same 0x address can exist on many chains, but a project may control it only on some; Protocol Guild, for example, publishes a different address for each network.
  • Send a small test first if the amount matters to you, and wait until it shows on the explorer.
  • Vesting and split contracts cannot send funds back. A mistaken transfer is usually permanent.
  • Check the address format against the network before you paste it: safe-send does this offline.

Where you can give

Protocol Guild Give today

What it funds
Ethereum's core protocol contributors: donations vest over time and are split among the Guild's members
How to give
Send ETH or an ERC-20 token to the donation vesting contract for your network, copied from the Guild's own donate page. 1-year contracts are for regular donations; 4-year contracts are for 'Pledge' donations from projects.
Networks
Vesting contracts on Ethereum mainnet, Arbitrum, Base and Optimism. Polygon, Robinhood Chain, Scroll, Shape, zkSync and Zora have multisigs only; the Guild periodically moves those funds into vesting contracts.
Watch out
Each network has its own address — the docs say mainnet and other-chain addresses differ. Vesting contracts accept only ETH and ERC-20 tokens and cannot claim funds; for anything else use that network's multisig listed in the docs. Contact the Guild before a Pledge so it can coordinate a test transaction.

Giveth Give today

What it funds
Individual public-goods projects that created a page on Giveth (creation is permissionless, so judge each project yourself)
How to give
Pick a project on giveth.io and donate from your wallet; the donation goes to the project address.
Networks
Base is one of the supported networks.
Watch out
Quadratic-funding matching only applies during a round, and we found no Base QF round for November 2026. Verification on Giveth is not an endorsement of a project.

Drips Give today

What it funds
Open-source software: any GitHub repository, or a curated Drip List that splits funds across projects by percentage
How to give
Use the Drips app to stream funds to a GitHub repo you depend on, or to a Drip List (ENS publishes one, for example). Streams can be adjusted any time.
Networks
Drips' home page does not name its networks; check in the app before funding.
Watch out
We did not verify how funds to a repository that has not set up Drips are handled; read the project page in the app before you start a stream.

Gitcoin (rounds) Watch — nothing open

How to give
No open round or campaign to donate to as of 2026-11-21. Wait for an announcement on gov.gitcoin.co rather than following links from replies or ads.
Networks
Varies by round
Watch out
Gitcoin said in April 2026 it is sunsetting the Gitcoin Grants program; an August proposal describes a new fund and an October 'Node Zero round' without dates. Anything calling itself 'GG26' should be checked against gov.gitcoin.co first.
